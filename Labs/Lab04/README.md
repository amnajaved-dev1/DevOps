# Lab 4: Simple Python Database Connections

## Overview
This repository contains the solution and required evidence screenshots for **Lab 4**, demonstrating database connectivity using Python with MySQL and MongoDB across multiple configuration sources (hardcoded values, environment variables, and configuration INI files).

## Repository Structure
- `Lab4_Solution.pdf`: Complete written answers, observations, and exam evaluation solutions.
- `screenshots/`: Contains all 15 required automated-grading terminal and workflow screenshots.

## Technologies Used
- Python 3 (`mysql-connector-python`, `pymongo`)
- Docker & Docker Compose (running MySQL and MongoDB containers)
- Ubuntu Server environment
